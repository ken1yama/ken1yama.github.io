# 山下 健一 | Ken-ichi Yamashita

GitHub Pages で公開する研究者ホームページです(静的サイト。ビルドは不要。HTML を直接編集します)。

| ファイル | 内容 |
|---|---|
| `index.html` | トップ(分子の表示、About、Research Topics、News、Contact) |
| `research.html` | 研究紹介 |
| `publications.html` | 論文リスト(絞り込み・検索・DOI・Graphical Abstract) |
| `gallery.html` | 論文の表紙 |
| `activities.html` | 招待講演、研究費、メディア、教育、学会活動 |
| `cv.html` | 職歴・学歴 |
| `software.html` | 公開しているアプリ |
| `links.html` | リンク集 |
| `style.css` | 共通デザイン |
| `assets/` | 画像(`ga/` Graphical Abstract、`cover/` 表紙、`photo.jpg` 写真)、分子表示(`hero.js`, `molecules.js`) |

## 公開
`ken1yama.github.io` リポジトリに、このフォルダの中身を置き、Settings → Pages で Branch を `main` / `(root)` にします。
