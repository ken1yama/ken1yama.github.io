OT-LCDFT-RCCS

長距離補正(LC)汎関数のパラメーター ω(および α, β)を、J² 値の最小化によって系ごとに最適チューニング(optimal tuning)する Python スクリプトです。分子科学研究所 計算科学研究センター(RCCS)のスーパーコンピューターで、Gaussian 16 のジョブを自動で投入しながら最適化を進めます。ブラウザで使うツールではなく、RCCS 上で実行します。

  • 中性・カチオン・アニオンの3状態を ΔSCF 法で計算し、J² を最小にするパラメーターを探索します
  • ω のみ、α のみ、ω と α の同時の3つのモードと、5種類の最適化アルゴリズム(Brent 法、黄金分割、グリッド、ベイズ最適化など)
  • 最適化全体を1本のジョブで実行し、前回の結果を初期値に使って高速化。中断した計算は途中から再開できます
  • J² 値だけを計算するモードと、OT と構造最適化を整合するまで繰り返すモード

CIF Completer

SHELXL で精密化した CIF に残る ? を、測定ソフトが出力したファイルの値で補完し、論文の SI 向けの Word の表を作ります。

  • 値が ? の項目だけを埋め、すでに入っている値は変更しません。どの項目をどのファイルから埋めたかを一覧で示します
  • Rigaku(.cif_od)、Bruker(.pcf。.p4p と .abs は試験的な対応)、他社装置の CIF 形式のファイルを読み込めます
  • 補完した内容は画面上で直接編集でき、checkCIF のページへのリンクがあります
  • 結晶データ、原子座標、結合長・結合角、異方性変位パラメータなどの表を、Word(.docx)で出力できます

Image Resizer (cm / dpi)

画像を切り抜き、印刷サイズ(cm)と解像度(dpi)を指定してリサイズ・保存します。論文の図を、指定の寸法と解像度にそろえる用途に向いています。

  • 幅・高さ(cm)と解像度(dpi)から、出力の画素数を計算します。PNG と JPEG には dpi を書き込むので、Word や Illustrator で指定の cm サイズとして扱われます
  • リサイズ方式を選べます(図・グラフ・文字向けのエリア平均、写真向けの Lanczos など)
  • 切り抜き範囲を全画像に適用する一括処理と、ZIP での保存
  • JPEG、PNG、WebP、GIF、BMP、SVG、TIFF の読み込みと、クリップボードからの貼り付けに対応

Gaussian / ORCA Output Parser

Gaussian と ORCA の出力ファイル(.out / .log / .txt)から、ジョブ種別、エネルギー、虚振動の数(NImag)、点群、温度、計算条件を取り出し、1つの表にまとめて CSV に書き出します。

  • Gaussian と ORCA を内容から自動で判別。両方を同時に読み込んで、1つの表にまとめられます
  • 2件以上を読み込むと、エネルギー差を別の表で表示できます(単位と基準を選択可)
  • SP / Opt / Freq / TD などに対応。不要な列は後から削除でき、CSV にも反映されます

TDDFT Spectrum Viewer

Gaussian の TDDFT 計算の出力ファイル(.out / .log)を読み込み、遷移テーブルと UV-Vis スペクトルを表示します。GaussSum のような使い方ができます。

  • 遷移テーブル(エネルギー、波長、振動子強度、対称性、主要な軌道の寄与)
  • スペクトルの表示(ガウス型・ローレンツ型、横軸 nm / eV / 10³ cm⁻¹、半値幅や範囲の調整)
  • 遷移テーブル(CSV)、スペクトル図(PNG / SVG)、スペクトルの数値(CSV)の保存
  • 開殻(UKS)の出力や、複数ステップのジョブに対応
